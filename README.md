# Employee Data Analysis Project

## Project Overview
This project focuses on analyzing employee data using Python and Pandas.

## Dataset
- Dataset name: employees.csv
- Format: CSV
- Source: Trainer-provided dataset

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- VS Code
- Git and GitHub

## Data Analysis
The following operations are performed:
- Dataset shape
- Dataset information using info()
- Statistical summary using describe()
- Missing value analysis using isna().sum()
- Duplicate record analysis using duplicated().sum()

## Business Questions
1. Which department has the highest number of employees?
2. Which department has the highest average salary?
3. Who is the highest-paid employee?
4. Which city has the most employees?
5. What is the average salary of employees in each city?

Initial dataset loading and data exploration completed.

## Day5 – Employee Data Analysis

### Project Overview
This project analyses employee salary data using Python to understand salary distribution, department salary differences and employee distribution across cities.

### Tasks Completed
- Task1: Data cleaning
- Task2: Exploratory data analysis (EDA)
- Task3: Five visualisations
- Task4: Report and presentation

### Project Structure
- `Day5/data/` – cleaned employee dataset
- `Day5/Task2/` – exploratory data analysis notebook
- `Day5/Task3/` – visualisation notebook and saved figures
- `Day5/Task4/reports/` – findings summary, HTML report and presentation

### Requirements
Install the required libraries:

```bash
pip install -r requirements.txt
```

### How to Run
1. Clone or download the project repository.
2. Open the project in VS Code.
3. Install dependencies using `pip install -r requirements.txt`.
4. Open the Jupyter notebooks inside Day5.
5. Run the notebook cells from top to bottom.
